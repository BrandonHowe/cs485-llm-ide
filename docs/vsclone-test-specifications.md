# VSClone Test Specifications

This document contains one English-language test specification per `VSClone` source file that still needs targeted coverage work or explicit unit-test planning. Each section lists the callable surface in that file and provides a test matrix with the purpose, inputs, and expected output for each test.

For module-only or type-only files, the section captures export-surface or compile-time contract coverage instead of callable behavior. This document is cumulative and includes the under-80 coverage subset identified on April 1, 2026.
